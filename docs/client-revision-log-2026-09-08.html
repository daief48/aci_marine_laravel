02

Products tab in the navigation

Added

A Products tab now sits in the main navigation between About Us and Projects. It has been added in three places so it works everywhere: the desktop navigation bar, the mobile menu, and the “Products & services” entry inside the dropdown menu — which previously pointed nowhere.

All three open a new full Products page listing every category with the products under it, each linking through to its own detail page.

Live at acimarine.com/products
03

Black product thumbnails on the homepage

Fixed

What was happening: the homepage cards were still pulling their thumbnail images from the old acimarine.com server, which no longer serves those files. The image failed to load, and each card’s dark gradient overlay — the shading that makes the category label readable — was left sitting over an empty box. That is the solid black you were seeing. The individual product pages used a different image source, which is exactly why those looked correct.

What we changed: thumbnails now load from your own server, and the site checks that the image file actually exists before using it, falling back to a known-good image instead of an empty frame. Any thumbnail you upload from the admin panel is used straight away.

Manage Products Catalog→Product Categories→Edit
04

Product reordering from the admin panel

Fixed & extended

Reordering now takes effect on the live site. Rather than typing order numbers by hand, there are two new drag-and-drop panels:

  • Product Categories — sets the order of the six cards in the homepage Products section. Drag the rows, then press Save Order to Homepage.
  • Products — a separate panel per category, setting the order of the product names listed inside each card and on the category page.

Saved changes appear immediately on the homepage, the Products page, and each category page — no cache clearing needed.

Manage Products Catalog→Product Categories/Products
05

Updating the homepage video

Ready — you can do this yourself

You no longer need to send us the file. The Hero Slider screen now takes a direct upload, and shows a live preview of how the video will look behind the headline before you save.

  1. Open Admin → Homepage → Hero Slider.
  2. In the Background Video Source box, switch to the Upload MP4 File tab.
  3. Click the upload area and choose your file. The name appears once selected.
  4. Check the Live Screen Mockup preview on the right.
  5. Press Save All Changes at the top.

The alternative Video URL tab still accepts a Vimeo or YouTube embed link if you would rather stream it. Whichever option you save last is the one that goes live.

Recommended file specification
Format MP4, H.264 codecWebM and OGG are also accepted
Resolution 1920 × 1080 (Full HD)4K adds load time without visible gain — the video sits behind text
Length 10 – 20 secondsIt loops continuously, so a seamless start and end works best
Audio None — mutedBrowsers block autoplay with sound, so any audio track is dead weight
Maximum size 100 MBWe recommend staying under 25 MB so the homepage stays fast on mobile
Framing Keep the lower third calmThe headline and button sit over the bottom of the frame
06

Dynamic Authorized Partnerships — About page

Built

Partnerships are no longer hard-coded. There is a new Authorized Partners section in the admin sidebar where you can add, edit, reorder and remove partners yourself. MHIET / Mitsubishi is now simply the first record in that list.

Each partner holds:

  • Partner name and role subtitle — e.g. MHIET Japan / Global Engineering & Technology
  • Badge text — e.g. Authorized Distributor, Exclusive Partner
  • Established year, logo upload, partnership description, website link
  • Display order, plus an active toggle to hide a partner without deleting it
Manage Authorized Partners→Add / Edit
07

Authorized Partners on the homepage

Added

A new Authorized Partnerships section now appears on the homepage, directly below the Products section, using the same records as the About page. Add or edit a partner once and it updates in both places — and on the Contact page.

If no partner is marked active, the section hides itself entirely rather than leaving an empty band on the page.

Upload limit on the hosting account

The panel accepts video files up to 100 MB. Some hosting plans cap uploads lower than that, in which case a large file can fail quietly. If your first upload does not go through, send it to us and we will place it directly and raise the limit.
